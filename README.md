# Social Video Generator Studio

App per agenzie immobiliari per creare reel e video ottimizzati per Instagram e Facebook partendo dalle foto delle proprietà.

## Funzionalità

- **Carica foto** dall'archivio fotografico (supporto cartelle multiple)
- **Seleziona formato video**: Verticale (9:16) per Reel/TikTok o Orizzontale (16:9) per post classici
- **Testo in sovrimpressione** personalizzabile (prezzi, titoli, call-to-action)
- **Base musicale** con anteascolto (3 tracce trend-free selezionabili)
- **Prompt IA** per descrivere le manipolazioni e lo stile del video
- **Genera payload** pronto per l'invio al servizio di generazione video IA

## Come usare

1. Clicca su "Carica Cartella Foto" e seleziona una cartella con le immagini delle proprietà
2. Scegli il formato video desiderato (9:16 verticale o 16:9 orizzontale)
3. Aggiungi il testo in sovrimpressione (es. prezzo o titolo della proprietà)
4. Seleziona la base musicale preferita e ascoltane l'anteprima
5. Scrivi il prompt IA descrivendo le transizioni e lo stile desiderato
6. Clicca su "Genera Reel per Instagram/Facebook" per impacchettare i dati

## Tecnologie

- HTML5 with Tailwind CSS via CDN
- JavaScript puro per la logica client-side
- File API per la lettura delle immagini selezionate
